Design Listening Lab 3.0

1. Upload all files in this folder to a HTTPS static web host such as GitHub Pages.
2. Open the HTTPS site in Safari on iPad while online, wait for the service worker to install, and add to Home Screen.
3. Open once while online; then test airplane mode. Local handwriting and transcripts are stored on this device, not synced.
4. Import your own legally obtained transcript and audio. The built-in paragraphs are original examples, not Netflix transcripts.
5. Local AI: open the AI panel while online and attempt to install a lightweight WebLLM model. Requires Safari WebGPU and adequate memory. Model caching and full offline AI are NOT guaranteed on iPadOS; test airplane mode after installation. The AI runtime itself is loaded from a CDN on first use.
6. Export JSON backups regularly. Browser storage can be evicted by iPadOS. The audio file is not persisted and must be selected again.
7. If a model does not load, the offline handwriting, imported text, and built-in dictionary remain functional.
