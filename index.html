播放设置

在播放位置设置 A 点和 B 点，即可循环听这一段。

导入英文原文

支持 TXT、SRT、VTT 或粘贴文字。长文会自动分成短段。SRT / VTT 的时间码会保留，用来播放对应音频。

校准段落音频

填写秒数（如 72.5）或分:秒（如 1:12.5）。也可以试听、拖动进度，再把当前时间设为开始或结束。

跳过片头与片尾

试听原音频，把第一句和最后一句对白标为正片范围。时间以原音频为准。

在线 AI · 安全连接

网页只保存你的代理服务地址。访问口令仅保存在当前打开的页面内存中，刷新后需要重新输入。不要在这里输入百炼或 OpenAI API Key：百炼或 OpenAI 的 API Key 必须存放在服务器密钥中。
